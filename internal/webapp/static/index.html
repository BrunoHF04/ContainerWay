          Passo a Passo: Deploy do Cliente
          
            
          
          
          
          
          
            
          
              1. Servidor Central (Windows Server)
              Certifique-se de que a VPS ou Windows Server está rodando o Headscale (porta padrão 8080) e que você gerou uma API Key executando o comando headscale apikeys create.
            
          
            
            
          
              2. Inicialização deste Painel
              Suba este ContainerWay passando a API Key e endereço do Headscale: ./containerway-web -hs-url="http://seu-server:8080" -hs-apikey="SUA_API_KEY".
            
          

            
          
              3. Gerar o Comando
              Na aba anterior, digite o nome do cliente (ex: cliente-loja-01) e clique em Gerar Comando de Instalação.
            
          

            
          
              4. Instalar no Cliente Linux
              Copie o comando gerado, abra o terminal do Linux do cliente e execute como superusuário (sudo). O script fará o download do binário do agente, criará o serviço systemd de inicialização automática no boot e ativará a VPN.
            
          

            
          
              5. Acesso Direto
              Conecte sua própria máquina de trabalho no seu Headscale usando o aplicativo Tailscale (tailscale login --login-server http://seu-server:8080). Agora você poderá acessar o cliente pelo navegador em http://cliente-loja-01:8765 ou SSH na porta 2222!
            
          
          
          
        
          
                

      
        
          
          
          Troca de senha obrigatória
          
          
          O administrador exige que você defina uma nova senha antes de continuar.
